# Parks n Peaks Spot Monitor — Android v1.0.22

First proposed GitHub Android tablet release (pre-release recommended initially).

## Highlights

- Live worldwide Parks n Peaks spots with Mode, Country, Program and Max Age filters.
- QRZ name lookups, Wanted Stations and master sound mute.
- Subtle new-spot highlighting, FT8 dial-frequency correction indicator and Park(s) count.
- Day/Night themes, landscape layout, Screen On/Auto and HF Conditions.
- Browser map links, feed diagnostics and offline Help & About.
- v1.0.22: improved empty-list display and aligned footer Help link.

## Requirements

Android 8.0+ tablet; landscape display; internet connection for live spots and optional services.

## Installation

Download the signed APK from **Assets** and open it on your Android tablet. Allow installation from your file manager if Android prompts you.

**Important for existing beta users:** A signed public release APK may not install over a development `app-debug.apk` because the signing keys differ. Removing the development app may remove its settings.

## Notes

This is a pre-release while we verify the signed distribution package. Send feedback through GitHub Issues. See `docs/android-installation.md` for full instructions.
