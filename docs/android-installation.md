# Install Parks n Peaks Spot Monitor on Android

**Version:** 1.0.22  
**Platform:** Android tablets, landscape orientation  
**Minimum Android version:** Android 8.0 (API 26)

## Installing the APK

1. In the project's GitHub **Releases**, find the release labelled `android-v1.0.22`.
2. Under **Assets**, download the Android APK (not the source-code ZIP).
3. Open the APK in your tablet's Downloads or Files app.
4. If Android prompts you, allow **Install unknown apps** for the file manager or browser used, then choose **Install**.
5. Open **Parks n Peaks Spot Monitor** and confirm you have an internet connection.
6. Set the Mode, Country, Program and Max Age filters to your preferences.

The app uses the Parks n Peaks spot feed. It is not affiliated with Parks n Peaks, QRZ.com or the BoM. Third-party services and their availability may change.

## Using the app

- **Refresh Spots:** update the spot list immediately; normally refreshes every 60 seconds while in use.
- **Wanted Stations:** add callsigns to highlight; optional separate alert preference.
- **Sound On/Off:** master mute; Sound Off stops all in-app alerts, Sound On restores individual sound preferences.
- **QRZ Names:** optional; enter your own QRZ account details if eligible for XML lookup.
- **Screen On/Auto:** prevent normal display timeout while using the app, or return to system timeout.
- **Theme:** tap for Day/Night; long-press for automatic-theme and other settings.
- **HF Conditions:** view ionospheric information; availability depends on the external provider.
- **Help:** cyan link along the lower-left footer, opens the offline help topics.
- **Tap a spot:** details, Copy Spot and Show on Map where supported.

## Updating

For an update to install over an existing public release, it must use the **same app ID and signing certificate**. An independently signed debug build typically cannot be updated directly with a new public release APK. If you must uninstall the old version first, back up your preferred settings; uninstalling may remove them.
